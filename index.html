현재 개요

브라우저 단독 모드 안내

현재 초안은 브라우저가 대상 사이트에 실제로 도달 가능한지를 보는 방식입니다. 추후 프록시나 서버를 붙이면 200/500 기준 모니터링으로 확장할 수 있습니다.

현재 브라우저가 오프라인 상태로 보입니다. 이 경우 모든 사이트가 장애처럼 보일 수 있습니다.

모니터링 요약

최근 이슈 피드

최근 실패, 타임아웃, 연속 장애 구간을 빠르게 훑어볼 수 있는 요약입니다.

30일 시간 집계

최근 30일 범위는 시간 단위로 압축 저장해, 저장량을 제한하면서 장기 추세를 보존합니다.

사이트 목록 설정

JSON 배열을 수정한 뒤 적용하면 목록이 브라우저 로컬에 저장됩니다. `id`, `name`, `url` 형식을 권장하며, 중복 `id`는 자동으로 정리됩니다.

행 단위로 수정한 뒤 `목록 저장`을 누르면 바로 반영됩니다. `id`가 비어 있으면 이름 기준으로 자동 생성됩니다.

고급 편집이 필요할 때만 JSON 편집기를 열어 사용할 수 있습니다.

예시: `[{"id":"komsco","name":"대표홈페이지","url":"https://www.komsco.com"}]`

브라우저 정책상 이 페이지는 대상 사이트의 상세 응답내용이나 정확한 상태코드를 읽지 못할 수 있습니다. 현재 초안은 운영진이 “접속 가능 / 지연 / 실패 추세”를 직관적으로 보는 용도에 최적화되어 있으며, 더 정밀한 SLA 관리는 추후 중계 서버나 사내 API를 붙이면 자연스럽게 확장됩니다.
